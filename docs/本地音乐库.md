# 本地音乐库

仓库不附带歌曲。安装后，在“② 出片设置 → 自动配乐来源”选择“本地曲库（推荐）”，导入自己的音乐文件夹。也可导入剪映缓存中的普通音频，使用权由素材授权决定。

## 导入与试听

1. 点击“导入音乐文件夹”或“导入剪映缓存”。默认只导入至少 120 秒的音乐，可把最短时长改为 0 接收短音频。
2. 默认曲库在项目根目录 `assets/local_music/`。可选择别的 `index.json`，后续导入保存到该索引所在目录。
3. 点击“刷新曲库”查看数量与时长，“试听随机一首”核对声音。无法恢复歌名时显示“曲库第 N 首”。

默认缓存来源为 `%LOCALAPPDATA%\JianyingPro\User Data\Cache\music`。只处理普通音频，不读取账号或密钥。导入会复制文件，不删除来源。

部分缓存实际是 AAC，却使用 `.mp3` 扩展名；导入按真实编码重封装为 M4A。MP3 保持 MP3，其他支持格式转换为 AAC。每个新音频完整解码后才加入索引，按内容排重，失败记录保留供检查，重复运行可续导。

## 配乐规则

- 每条成片从库中随机排列不同歌曲，顺序覆盖全部尾图，只有最后一首超出的部分截断。
- 前面视频保留原声，自动配乐只位于产品图尾段。
- 歌曲路径、SHA256、时间位置和裁切时长写入计划；续跑沿用已选歌曲。
- 音频缺失、被改写或不同歌曲总时长不足时明确报错，不自动回退云端。
- “仅将本批配乐换为本地”只更换当前批次的音乐，先备份计划；视频、图片、特效和位置保持原样，完成 MP4 的计划跳过。
- “应用到本批计划”属于完整包装更新，可能重抽特效，仅需更换音乐时请用专门的配乐按钮。

## 保存和迁移

`audio/` 保存音频，`index.json` 记录编号、原文件名、时长、路径和校验值；`library.json` 保存导入统计，`.imports/` 保存续导检查点。这些内容均被 Git 忽略。

导入后清理剪映来源缓存不影响独立曲库，但应保留 MixCut 曲库文件。迁移曲库时完整复制目录，并重新选择索引；索引使用相对音频路径。已有计划仍引用生成时的路径，迁移后需重新生成计划或使用本批音乐替换。

## 命令行

```powershell
.\run.bat harvest-music --source "C:\MyMusic" --min-seconds 120
.\run.bat harvest-music --source "C:\MyMusic" --target "C:\MixCutMusic" --min-seconds 60
.\run.bat localize-music --batch current --index "C:\MixCutMusic\index.json"
.\run.bat render
.\run.bat batch-draft
```

本地曲库的随机多曲自动包装目前面向剪映草稿。直接 FFmpeg 输出使用“本地音乐文件”的单曲配置，不渲染剪映原生特效。
