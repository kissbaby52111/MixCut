# MixCut

<img src="assets/icons/mixcut-feather.png" width="72" alt="MixCut 蓝色羽毛图标">

Windows 本地电商视频批量混剪工具。把准备好的视频放进不同文件夹，随机组合片段，再追加产品图片、配乐和特效，生成剪映草稿或 MP4。使用原生桌面界面，不需要搭建服务。

## 功能

- 按段落文件夹随机选材，默认顺序：开头 → 开头转化点 → 达人介绍 → 明星产品介绍 → 收尾转化点；可改名、排序、增删。
- 每条成片随机选四张不同产品图追加到尾部，默认每张 300 秒，可自行调整。
- 本地曲库导入、按内容排重、试听与完整性校验。多首随机音乐依次铺满图片尾部，末曲超出部分截断，前面视频保留原声。
- 剪映原生特效从人工整理的 40 种氛围、18 种动感候选中随机抽取 3+2 种，同时覆盖每张尾图。候选池不是剪映官方完整分类，不能保证每种组合都适合所有产品图。
- 可选四角产品图：随机选四张、保持比例、贴紧四角，覆盖整个成片；默认关闭。
- 可选“拽酷墨镜”：跳过开头视频，从下一段覆盖至结尾；默认关闭。识别效果和使用权限由客户端决定。
- 批次独立、计划固定、组合排重和续跑。新增批次不会自动合并历史计划；排重不保证平台认定为原创内容。
- 一个批量复合草稿包含多条独立成片，在剪映主时间线全选后可使用“导出所选片段”。

## 环境与安装

Windows 10/11 x64、Python 3.11+（安装时包含 Tk 和 pip）。剪映草稿功能还需要本机剪映专业版；草稿结构曾在 11.1 验证，其他版本需自行核验。

```powershell
git clone https://github.com/kissbaby52111/MixCut.git
cd MixCut
.\setup.bat
.\start.bat
```

`setup.bat` 下载 FFmpeg/FFprobe、安装 Python 依赖到 `.runtime/packages`，并从模板生成 `config.json` 和 `.env`。已有配置不覆盖。下载需要联网；默认 Python 包源为清华镜像，二进制由固定来源下载并校验摘要。仓库不包含运行时二进制、音乐或商品素材。

需要桌面快捷方式时，安装后执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\install_desktop_shortcut.ps1
```

## 第一次使用

1. 打开“① 素材与顺序”，选择各段视频文件夹和产品图文件夹。至少准备四张内容不同的产品图，各视频段落至少一条视频。
2. 在“② 出片设置”设置数量、画幅、每张尾图时长。默认是“剪映草稿 → 自动包装 → 本地曲库”，先导入自己的音乐文件夹；不同歌曲总时长须足以覆盖尾图。
3. 按需开启四角图或人物墨镜。若使用原生特效，检查客户端素材是否可用及是否需 VIP/SVIP。
4. 生成计划并生成本批草稿。在“③ 计划与成片”查看批次、状态、包装清单和结果目录。续跑沿用已选视频、图片、歌曲与特效。
5. 将“草稿保存目录”设为剪映的草稿目录；生成后返回剪映首页打开同名草稿。素材和本地曲库必须保留在计划记录的位置。

每条默认时长为所选视频总长 + 20 分钟图片。可先把每张图改为几秒，验证效果后再批量生成。

## 输出与导出

| 方式 | 结果与边界 |
| --- | --- |
| 剪映草稿 | 保留原生特效及可编辑轨道，需要剪映加载与渲染。生成成功不代表 MP4 已导出。 |
| 批量复合草稿 | 每个复合片段是一条成片。主时间线选中片段 → Ctrl+A → 右键“导出所选片段”；客户端支持时勾选“导出时包含视频效果”。普通右上角“导出”会导出整个长时间线。 |
| FFmpeg MP4 | 无需剪映，可用本地单曲、四角图、程序流星或本地特效视频。无法渲染剪映原生特效，不能当作原生草稿的等价导出。 |

批量草稿是“一条主时间线 + 每条成片一个扁平子时间线”，避免多层嵌套导致媒体丢失。五种效果附加在尾图段上，四角图在上层视频轨。

剪映导出仍由用户在客户端执行，当前未提供无人值守控制剪映、逐批自动导出 MP4 的完整功能。云端音乐为兼容旧计划保留，ID 可能失效，推荐使用本地曲库。

## 命令行

```powershell
.\run.bat doctor
.\run.bat init
.\run.bat harvest-music --source "C:\MyMusic" --min-seconds 120
.\run.bat plan --count 10
.\run.bat render
.\run.bat batch-draft
.\run.bat inspect-draft "C:\MyDrafts\MixCut_..."
.\test.bat
```

`render`、`batch-draft` 默认仅处理当前批次；可用 `--batch 编号` 指定旧批次，只有显式 `--all` 才处理全部历史。自定义配置放在子命令前：`.\run.bat --config "C:\MyProject\config.json" status`。

合成素材演示：`.\run.bat demo --tail-seconds 2 --width 360 --height 640`。生成到 `examples/`，不使用真实商品素材、平台采集或付费 AI。

## 配置、数据与开发

- `config.example.json` 是通用模板；本机 `config.json`、`.env`、`.runtime/`、`workspace/`、`examples/` 及本地曲库内容均不提交。
- 默认工作流 `folder_mix` 不调用 AI。可选采集/分类模式见 [AI 流水线](docs/AI_pipeline.md)，API Key 只在本地 `.env` 或环境变量配置。
- [本地音乐库](docs/本地音乐库.md) · [开发说明](CONTRIBUTING.md) · [第三方来源](THIRD_PARTY_NOTICES.md)
- 自动归档旧剪映草稿默认关闭；开启后会移动旧 `MixCut_*` 草稿到归档目录。先确认输出目录属于自己的工作空间。

测试使用合成媒体和模拟接口。原生特效的实际显示、平台素材权限和不同剪映版本的导出需要客户端验证；测试不会调用个人平台账号或付费模型。
